# triage: perl backend can't render what the py-sh-go frontend emits

## NEED
The perl renderer must handle this A1 (the estree reference renders it and
matches native).

## FAILING-CASE
frontend py-sh-go, example t97_list_growth100min.py (cross-product pair).

## EVIDENCE
estree matches native; perl differs

## OUTCOME: rejected: backend-owned, not core — the perl renderer (shir_to_perl) lives in src/perl_backend.rs / src/ir.rs and is owned by the perl backend worker. The shared core (parser/IR/A1 encoding) is not implicated: the same case renders correctly from the core CLI, so this is perl-renderer coverage, not a core defect.
