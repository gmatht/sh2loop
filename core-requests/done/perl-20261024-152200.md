## NEED

In `classify_builtin_writes`, a word is a command-line FLAG only if it
actually carried a leading `-`. Today the dash is stripped BEFORE the test, so
a bare 1–2 letter VARIABLE NAME is indistinguishable from `-i` and is dropped:

```rust
let s = s.trim_start_matches('-');
if s.is_empty() || (s.chars().all(|c| c.is_ascii_alphabetic()) && s.len() <= 2) {
    continue; // a flag like -i/-r/-x/-a/-A/-l/-u/-n/-g/-t/-p/-f/-F
}
```

`x` is not a flag. The dropped write leaves the variable looking single-def, so
`fold_param_const`'s `(":-", 3)` arm substitutes the pre-`unset` literal.
