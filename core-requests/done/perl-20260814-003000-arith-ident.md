# perl: arith node type "Ident" round-trips through --shir but the deserializer (and ArithAst) has no such variant — 6 corpus files fail shIR ingress

## NEED
The A1 `Arith` vocabulary must include the `Ident` node the emitter
already produces: `{"name": "i", "type": "Ident"}` inside `Arith` trees
(from `total=$(( total + i ))` where the parser resolved a bare
identifier — the `$((...))` parser path emits `Ident` while the
`((...))`-statement path emits `Var`). The worktree deserializer
(`shir_json_in.rs::arith_from`) rejects it with
`Program.stmts[...].expr.ast.rhs.type: unknown arith type "Ident"`, so
the perl backend's `--shir-in-perl` ingress exits 1 and 6 corpus files
count as gate failures that no backend renderer can fix.

## WHY
Failing files (all exit rc=1 at ingress, before any rendering):
- `frontends/posix-sh-go/testdata/t48_accum.sh`
- `frontends/posix-sh-go/testdata/t51_arith_loop.sh`
- `sh2perl/examples/063_20_final_complex_construct.sh`
- `sh2perl/examples/063_hard_to_parse.sh`
- `sh2perl/examples/089_for_in_arith.sh`
- `sh2perl/examples/092_for_arith_func.sh`

Minimal repro: `total=$(( total + i ))` (089_for_in_arith.sh line 6)
emits `Arith::Bin{op:"+", lhs:Var("total"), rhs:Ident("i")}`.

## MINIMAL-CORE-CHANGE
In `src/ir.rs`: add `Ident(String)` to `enum ArithAst` (semantics: a
bare identifier read — identical to `Var` for the renderers).
In `src/shir_json_in.rs`: add `"Ident"` to `KNOWN_ARITH` and map it to
`ArithAst::Ident(name)`.
In `src/shir.rs` (or wherever ArithAst is rendered to ESTree) and any
exhaustive `ArithAst` matches (`estree.rs`, legacy `ir.rs` expr
renderer): render `Ident(name)` exactly like `Var(name)`.
Serialization shape is already emitted; no `shir_json.rs` change
needed.

## FAILING-CASE
```sh
#!/bin/bash
total=0
for i in 1 2 3 4 5; do
    total=$(( total + i ))
done
echo "total=$total"
```
`debashc --shir f.sh --raw | debashc --shir-in-perl -` → exit 1,
`unknown arith type "Ident"`.

Verified already in the tree: ArithAst::Ident + KNOWN_ARITH "Ident" (and "Cast") are present; all 6 listed corpus files round-trip `--shir | --shir-in-perl` with exit 0 (the `total=$(( total + i ))` repro emits Ident and ingresses).
