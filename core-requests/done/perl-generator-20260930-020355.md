## Remaining 45 — classified, with emitted evidence and the core site

### A. `unset` of an exported var does not clear `%ENV`; subshells are not forks (2)
`064_20_nested_subshells_environment_variables.sh`, `064_hard_to_generate.sh`.

`unset DEBUG` for an exported DEBUG emits only symbolic-package undefs:
```perl
do { { no strict 'refs'; undef ${'DEBUG'}; undef @{'DEBUG'}; undef %{'DEBUG'}; } … };
```
It never touches `$ENV{DEBUG}`, so a later `${DEBUG:-unset}` still reads `1`.

A text-level `delete $ENV{DEBUG}` makes the **inner** read right but breaks the
**outer** one, because the Perl lowering of `( … )` is an in-process block, not a
real fork — the delete leaks out of the intended subshell scope (verified; the
fix was written and reverted). Two coupled core needs: (1) exported `unset`
must delete the `%ENV` slot; (2) group commands need real scope (fork, or
save/restore `%ENV` around the block). Refs: `emit_stmt`'s unset arm; the group
command arm.

### B. `2>FILE` is emitted identically to `>FILE` — STDERR is never distinguished (1 + collateral)
`sync-direct-call-await.sh` (`echo hi 2>/dev/null` writes "hi" to /dev/null
instead of passing it through). Verified: generating `echo hi >/dev/null` and
`echo hi 2>/dev/null` produces **byte-identical** Perl:
```perl
open(my $__sh2_rfh0, '>&', \*STDOUT) …
close(STDOUT); open(STDOUT, '>', "/dev/null") …   # should be \*STDERR / STDERR
```
Ref: the redirect site at `ir.rs:~2304` (dup/close of `STDOUT` with no fd-2
branch). This is also why 2> redirects are "droppable" at `ir.rs:2616` — they
were never correct to begin with.

### C. Command substitution / `.` / `eval` lower to `bash -c`, which cannot see shell state (8)
`dot-source-lib.sh`, `parse-eval-multiline.sh`, `realpath-cmdsub.sh`,
`tty-cmdsub.sh`, `typeset-cmdsub.sh`, `qx-var-builtin-cd.sh`, `grep_p.sh`,
`sqs-overlap-multiline-awk.sh`.

`. ./lib_tmp.sh` → `coreutils-ffi: unknown util '.'`; `eval '…'` → `unknown
util 'eval'`; `try(){…}; $("${cmd[@]}")` → `bash: line 1: try: command not
found`; `$(cd -- "$(dirname "$0")" && pwd)` → `bash: line 1: cd: do { … }: No
such file or directory`. The inner command text is rebuilt as shell and handed
to `bash -c` (or the uu multicall), so shell *functions* and *builtins* that
were lowered to Perl are invisible. Needs `stmts_to_shell_cmd` / `expr_to_cmd`
(`ir.rs:6045/5616`) to refuse (→ native lowering) for a body that references a
defined function or a non-multicall builtin (`cd`, `.`, `eval`, `local`,
`typeset`).

### D. Shell state read by children before `export` (1)
`045_shell_calling_perl.sh`. `SHELL_VAR="Hello World"` emits
`$ENV{SHELL_VAR} = "Hello World";` — a plain assignment already mutates `%ENV`,
so the child `perl -e '… $ENV{SHELL_VAR}'` sees it before the `export`
(`export SHELL_VAR` then emits the no-op `$ENV{SHELL_VAR} = $ENV{SHELL_VAR};`).
Correct: assignment writes a lexical; only `export` copies to `%ENV`.

### E. Arrays (3)
* `063_09_complex_function_parameter_handling.sh`: `local -a args=("$@")` emits
  `my @args;` with **no assignment** → `Processed 0 options`.
* `064_07_complex_array_operations.sh`: `config` is declared **both** `my %config;`
  and `my @config;` (ARRAY_VARS/HASH_VARS census collision) → `Config: ` empty.
* `063_01_deeply_nested_arithmetic.sh`: arithmetic `%` loses its grouping —
  `(e % f)` renders as `… / int($e) % $f`, and `/ %` have equal precedence in
