## WHY (the hunk is a real committed bug either way, and it is ESTREE-visible)

`classify_builtin_writes` strips the dash BEFORE deciding an argument is a flag:

```rust
// src/transforms/copy_propagation.rs:409-412 (live) / :387-390 (HEAD)
let s = s.trim_start_matches('-');
if s.is_empty() || (s.chars().all(|c| c.is_ascii_alphabetic()) && s.len() <= 2) {
    continue; // a flag like -i/-r/-x/-a/-A/-l/-u/-n/-g/-t/-p/-f/-F
}
```

`unset x` therefore records **no write to `x`** (the name is 1 alphabetic char, exactly
the flag shape), and copy-propagation still believes `x` holds its single assigned
literal. This is committed code, and it is already unsound on HEAD with no WIP involved:

```
$ printf 'x=5\nunset x\necho "$x"\n' > /tmp/plain.sh
$ SH2_TRANSFORMS=copy-propagation otranspilerl-cli --target shir /tmp/plain.sh |
    jq -c '.stmts[-1].expr.args[1].elements[0]'
{"style":"DoubleQuoted","type":"Str","value":"5"}     # bash prints an empty line
```

That is an A1-contract corruption for **every** target (estree, c, go, java, python,
rust, zig — not perl), which is the point worth acting on under "shared core's
estree-facing parts": the A1 exporter exports a program whose printed output contradicts
bash. The WIP `fold_param_const` only widens the same mis-accounting to the `:-` family,
which is what makes the perl gate (whose arm diffs the render's stdout against bash —
`equiv: 642 pass, 1 fail`) the place it surfaces; the A1 itself is wrong for every
target.

End-to-end attribution with the live binary, no core edit. The sharpest evidence

## MINIMAL-CORE-CHANGE

Decide "flag" from the argument's own leading dash instead of from the trimmed text:

```rust
for a in args {
    if let IrExpr::Str(s, _) = a {
        let raw = s.trim();
        if raw.is_empty() || raw.starts_with('-') {
            continue; // a flag like -i / -r / --export
        }
        let name = raw.split('=').next().unwrap_or(raw);
        if !name.is_empty() {
            site(
                counts,
                values,
                name,
                &IrExpr::Str(raw.to_string(), crate::ir::StrStyle::DoubleQuoted),
                false,
            );
        }
    }
}
```

Soundness direction: this only ADDS writes to the map. An extra write cancels a fold
(REFUSE > GUESS); it can never invent one. `unset -v x`, `read -r line`,
`declare -i n=1` keep working (`-v`/`-r`/`-i` are skipped, `x`/`line`/`n=1` count), and
`--`-style long flags are skipped by the same test.
