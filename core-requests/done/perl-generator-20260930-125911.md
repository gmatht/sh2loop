## 3. Triage of the 55 (measured this round, existing binary, no rebuild)

Three of the 55 (`grep_p`, `dq-hashbang-multiline-assign`,
`103_pipeline_failure_multi`) **pass** and are contention artifacts of parallel
gates; the real count is 52. Grouped by root cause:

**(a) Generator bugs — real, but each lives in `ir.rs::shir_to_perl`:**

| # | Example | Emitted Perl | bash | Why |
|---|---|---|---|---|
| 1 | `variable-plus-operator` | `length($ENV{MYVAR}) ne 0` | no print | `${MYVAR+set}` is a *definedness* test, not a *length* test |
| 2 | `printf-format-and-v` | `printf("...%b...")` | `a\tb` | Perl has no `%b`; coerces numerically → `0` |
| 3 | `parse-dollar-single-quote` | `printf("%q", X)` | q-quoted | Perl has no `%q` |
| 4 | `parse-redirect-in-case-pattern` | `($words{$counter}) =~ /^\Q$(...)\E$/` | `match` | `$(...)` in a case pattern must be evaluated; also `%words{""}` |

(1) is the shape Fix 12 in the lost round targeted. These are all genuine
generator defects — but they are in the file I may not touch.

**(b) Parser gaps — the construct has no IR node at all, so no backend can fix it:**

`${VAR+word}` / `${VAR-word}` (no leading colon) is **not modelled anywhere.**
`parser/words.rs:2405-2447` handles `:-`, `:=`, `:+`, `:?` and the substring
forms; there is no branch for the bare `+`/`-` forms, and the enum
`ParameterExpansionOperator` (`ast_words.rs:68`) has **no variant** for them —
so `${MYVAR+set}` falls through to a plain variable read and is *silently
wrong*, not refused. The same arm shows `:+" alt"` lowered to
`DefaultValue(alt)`, i.e. `:+` is itself mistyped as the default operator.

**(c) Unsupported-construct refusals (by design, per `a2debd4f7`):**
`heredoc-unclosed` → `die "… not yet supported (redirect)"`; `063_hard_to_parse`
exits 2. These are refuse-loudly, which is the correct call, and are not
"fixable" without new IR nodes.

**(d) Environment-dependent / concurrency:** `096_head_procsub`,
`parse-error-block-in-pipeline` produce 1 MB+ of output (exit 124) — the
runaway class the 1 MiB stdout cap was added for. `sqs-overlap-multiline-awk`
fails with `Interactive mode requires a TTY` — an `awk` invocation reaching a
TTY-sensitive path under the gate's non-TTY capture.
